# cryptopal crypto工具箱
## 分析
首先就是为了做一个自己需要的程序，而不是为了服务用户而开发。
市面上的撸毛指纹浏览器不安全，并且批量管理浏览器与账号较为麻烦，因此希望能自己开发一个撸毛管理工具，使用原生 chrome 浏览器做交互。
除此之外，主流指纹浏览器的市场并不完全面向 web3，因此很多 web3 特色功能都没有做集成。
当然也不局限于撸毛，web3实际上有很多小功能可以集成在桌面软件中。 暂且可以划分为两个区：撸毛区与套利区。
## 功能概述（初步设想）
+ 登录（预留）
+ 指纹浏览器基本实现
  + 环境管理：新建浏览器及其配置（基础设置、代理信息、账号平台、指纹配置、高级信息）
  + 分组管理：一个组下有一个组长账户和多个组员账户
  + 插件管理：浏览器预安装插件
  + 代理管理：新增后，可用于新建浏览器时选择代理信息
+ 撸毛日志
  + 新增任务
  + 为分组/账户做周期打卡
  + 消耗gas统计（低优先）
+ 小工具（撸毛区）
  + 代币归集与分发（涉及到多个链）
    + 多对一归集：将选中账户的指定代币转入指定账户（涉及 gas 与代币分发）
    + 一对多分发：某个地址向账户组分发代币（通常是交易所提币到一个组长账户，再辐射分发给组员账户）
  + 交易所提币模块（从交易所提币防女巫，代币分发会用到）
